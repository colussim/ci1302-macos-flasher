# M5Stack M147 hardware notes

Use the [official M147 schematic and pin map](https://docs.m5stack.com/en/module/Module_ASR)
as the source of truth for your board revision. The module's USB-C connector is
the CI1302 programming interface and does not supply 5 V to M5-Bus. Programming
is performed with the host/Tab5 disconnected so UART signals are not driven by
two hosts. Power off before stacking/unstacking or changing DIP switches.

Each RX/TX DIP bank routes one UART signal to selectable bus positions.
**Do not enable all selectors:** multiple enabled selectors join bus pins
together. Select one route per bank and verify the numbers on the board.

For the reviewed M147 revision with RX labels Basic GPIO34/13/16/3 and TX labels
Basic GPIO12/15/17/1, switch **3 ON and 1/2/4 OFF in both banks** selected M5-Bus
module RX15/TX16. This retained routing was used during the recorded test. These
printed Basic/Core GPIO numbers are not Tab5 GPIO numbers and are not a universal
recipe for another hardware revision.

| Module M5-Bus RX / TX | Tab5 host TX / RX GPIOs |
|---|---|
| 15 / 16 | 7 / 6 |
| 22 / 21 | 48 / 2 |
| 26 / 23 | 51 / 47 |

This table is for host integration after programming, not an instruction to wire
the programming USB adapter manually. Do not assume a bare CI1302 board has the
same supply, reset circuit, or UART routing as M147.

The factory recognition UART is 115200 8N1. Programming uses a separate sequence
of handshake/agent/firmware rates; it does not change recognition UART settings
unless your supplied firmware changes them. The wrapper does not set a wake
phrase, wake ID, language, or spoken reply; those belong to the generated
firmware and the host configuration.
